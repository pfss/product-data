DATA — Stored in an embedded SQLite database (plans, quarters, plan_metrics, elasticity_assumptions, model_constants tables), queried live in-browser via sql.js (SQLite compiled to WebAssembly). No server, no external API calls at runtime.
METHODOLOGY — %ΔSubscribers = price elasticity × %ΔPrice (constant-elasticity approximation). Revenue = subscribers × ARPU, recomputed at the new price/quantity point. WTP ranges are illustrative p25/median/p75 markers, not measured conjoint data. A tier is flagged high churn-risk when the projected subscriber decline exceeds the model's threshold. Directional scenario tooling for pressure-testing pricing trade-offs, not point-estimate financial guidance.
Built as a work sample for the Pricing Strategy Manager role at Netflix.
