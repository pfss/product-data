DATA — Stored in an embedded SQLite database (formats, quarters, quarterly_metrics, allocation_defaults, model_constants tables), queried live in-browser via sql.js (SQLite compiled to WebAssembly). No server, no external API calls at runtime.
METHODOLOGY — ROI Index = (retention lift in bps × illustrative value-per-bps) ÷ format budget. Cost/member-hour = format budget ÷ projected member-hours generated. Directional scoring tools for comparing formats without an established benchmark, not point-estimate financial guidance.
